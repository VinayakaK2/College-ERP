Build a complete production-ready frontend for "TestForge Pro" — a Question Paper Generator Platform for JEE/NEET/Board exams. This is a full React + Vite + Tailwind CSS app.
---
## TECH STACK
- React 18 + Vite
- React Router DOM v6
- Zustand (auth store + paper builder state)
- TanStack Query v5 (data fetching)
- Axios (API calls)
- Tailwind CSS
- Lucide React (icons)
- React Hot Toast (notifications)
- React Dropzone (file upload)
---
## DESIGN THEME
Dark editorial theme. Deep navy background (#060a14). Electric blue accent (#3b82f6). Amber pop accent (#f59e0b). Font: poppins(display/headings) + Outfit (body) + DM Mono (labels, badges, numbers) from Google Fonts. No purple gradients. No generic AI look.
